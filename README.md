# Superstore Data Story: Where Is Profit Leaking?

## Central Question
Sales are growing, so where is profit being lost?

## Story Flow
1. Context: Sales grew 51% since 2023, but profit margin is only 12.6%
2. Problem: Furniture has a 2.6% margin vs about 17% for other categories
3. Evidence 1: Tables, Bookcases and Supplies are loss-making sub-categories
4. Evidence 2: Orders with more than 20% discount lost $136K
5. Recommendation: Cap discounts at 20% and review Furniture pricing

## Tools Used
Microsoft Excel (data analysis), PowerPoint (visual story)

## Dataset
Sample Superstore Dataset (2023-2026)
